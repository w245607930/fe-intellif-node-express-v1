# 队列与 Worker 规范

队列名称使用 `system`，Redis 前缀为 `fe-intellif:<env>:queue:bullmq`；任务名称使用稳定的小写标识。任务 payload 必须先通过 Zod Schema，禁止把密码、Token 或完整请求体放入任务数据。

API 进程只负责入队，Worker 进程只负责消费。`npm run worker` 启动独立 Worker，`npm run scheduler` 启动唯一调度进程；生产环境由 PM2 将调度器配置为单实例，API/Worker 可按需扩容。调度器使用 BullMQ Job Scheduler，避免每个 API 实例重复创建定时任务。

默认任务最多重试 3 次，采用指数退避；完成任务保留 24 小时，失败任务保留 7 天。业务幂等键经过 SHA-256 后作为 Job ID，既避免重复副作用，也不把原始标识写入 Redis Key 或日志。

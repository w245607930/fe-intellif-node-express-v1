# 日志与运行诊断规范

应用统一输出 Pino 结构化日志。HTTP 日志包含 Request ID、方法、路径、状态码和耗时；认证成功后的请求日志额外关联用户 ID。错误日志保留服务端诊断所需的错误栈，但响应只返回稳定错误码、消息和 Request ID。

开发环境输出标准输出，便于本地调试；生产环境由进程管理器收集标准输出/错误输出，并按天轮转、保留 14 天，禁止业务代码自行写入未受控日志文件。日志轮转策略在部署阶段由 PM2 或主机日志组件配置。

以下字段始终脱敏：密码、Authorization、Cookie、Access Token、Refresh Token、数据库连接串和 API Key。日志不得记录完整请求体或个人敏感信息。

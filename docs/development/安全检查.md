# P6 安全检查记录

## 检查项

- `npm run security:check` 扫描已纳入 Git 的源码、配置和文档，测试夹具与 `.env.example` 使用明确的无效占位值，因此不作为凭据判断对象。
- `npm audit --omit=dev --audit-level=high` 已执行。当前生产依赖树报告 Prisma 相关高危项和 `qs` 中危项；Prisma 版本按项目约束固定为 6.19.3，不能使用审计建议的降级版本，`qs` 由上游 Express 依赖引入。发布前需重新复核上游修复版本，不得使用 `npm audit fix --force` 绕过版本约束。
- 完整依赖树另有测试工具链漏洞，不进入生产镜像，但应在 P8 统一升级窗口处理。

审计结果属于风险登记，不代表忽略漏洞；每次依赖变更和发布前必须重新执行上述命令。

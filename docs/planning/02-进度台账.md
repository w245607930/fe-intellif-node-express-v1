## 5. 阻塞与风险动态

### 当前阻塞

- 当前无已确认阻塞项。队列依赖和 Redis 版本需在发布前复核兼容性。

### 高优先级风险

- Redis 单点影响多个基础能力。
- Refresh Token 重放与撤销设计不当。
- RBAC 权限缓存失效导致越权。
- BullMQ 任务重复执行产生重复副作用。
- PM2 Cluster 导致定时任务重复调度。

具体评分和缓解措施见《决策与风险登记》。

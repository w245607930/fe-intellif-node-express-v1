## 5. 阻塞与风险动态

### 当前阻塞

- 本机 `127.0.0.1:3306` 未监听 MySQL，且 `TEST_DATABASE_URL` 未配置，无法安全执行数据库集成测试。
- 远程开发数据库不符合测试库保护规则，不得用于清理、唯一约束或级联删除测试。

### 高优先级风险

- Redis 单点影响多个基础能力。
- Refresh Token 重放与撤销设计不当。
- RBAC 权限缓存失效导致越权。
- BullMQ 任务重复执行产生重复副作用。
- PM2 Cluster 导致定时任务重复调度。

具体评分和缓解措施见《决策与风险登记》。

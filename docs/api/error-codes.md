# 错误码目录

所有错误响应均使用 `{ code, message, data: null, requestId }` 结构；`requestId` 与响应头 `X-Request-Id` 一致。

| Code | 含义 |
|---:|---|
| 40001 | 请求参数校验失败 |
| 40002 | 请求体不是有效 JSON |
| 40100 | 未认证或认证凭据无效 |
| 40300 | 已认证但没有权限 |
| 40400 | 接口或资源不存在 |
| 40900 | 资源冲突（例如唯一标识重复） |
| 50300 | 请求处理超时 |
| 50301 | Redis 等依赖服务不可用 |
| 50000 | 服务端内部错误 |
